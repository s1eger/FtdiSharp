# FtdiSharp

**FtdiSharp** — управляемая библиотека на C# для работы с устройствами FTDI через нативный драйвер **D2XX**. Проект предоставляет объектно-ориентированную обёртку над FTDI API: поиск устройств, открытие каналов, обмен данными, настройку последовательного порта и доступ к дополнительным функциям устройства.

## Возможности

- получение количества подключённых FTDI-устройств и списка их параметров;
- создание стандартных или пользовательских описаний устройств через фабрику;
- открытие устройства по индексу, серийному номеру, описанию или расположению;
- чтение и запись массивов байтов;
- получение состояния очередей приёма и передачи;
- настройка скорости передачи, битов данных, стоп-битов, чётности и управления потоком;
- управление сигналами DTR и RTS;
- настройка таймаутов, таймера задержки и USB-параметров;
- сброс устройства и порта, очистка очередей, управление состоянием Break;
- работа с битовыми режимами FTDI;
- чтение, запись и очистка EEPROM, включая пользовательскую область;
- выполнение vendor-specific команд;
- получение версий драйвера и библиотеки D2XX, а также номера COM-порта;
- безопасное освобождение нативного дескриптора через `SafeHandle`.

## Требования

- **.NET 10** или совместимый SDK для сборки проекта.
- Нативная библиотека **FTDI D2XX** (`ftd2xx`), доступная в используемой операционной системе.
- Установленный драйвер и подключённое FTDI-устройство для выполнения операций с оборудованием.

## Быстрый старт

```csharp
using System.Text;
using FtdiSharp;

var settings = new FtdiSettings
{
    BaudRate = 115200,
    DataBits = FtdiDataBits.BITS_8,
    StopBits = FtdiStopBits.ONE,
    Parity = FtdiParity.NONE,
    ReadTimeout = 1000,
    WriteTimeout = 1000
};

var ftdi = new Ftdi(settings);
var devices = ftdi.GetDevices();

if (devices.Count == 0)
{
    Console.WriteLine("FTDI-устройства не найдены.");
    return;
}

using var channel = devices[0].OpenBySerial();

byte[] request = Encoding.ASCII.GetBytes("Hello, FTDI!");
uint written = channel.Write(request);

byte[] response = new byte[1024];
uint read = channel.Read(response);

Console.WriteLine($"Отправлено байтов: {written}");
Console.WriteLine($"Получено байтов: {read}");
```

При открытии канала применяются настройки из `FtdiSettings`. Канал реализует `IDisposable`, поэтому его следует освобождать через `using` или явным вызовом `Dispose()`/`Close()`.

## Пользовательские типы устройств

Метод `GetDevices()` по умолчанию возвращает коллекцию `FtdiDevice`, создаваемую с помощью `DefaultFtdiFactory`. Для получения коллекции собственного типа реализуйте `IFtdiDevice` и `IFtdiDeviceFactory<T>`, а затем передайте фабрику в обобщённый метод:

```csharp
var devices = ftdi.GetDevices(new MyDeviceFactory());
```

Здесь `MyDeviceFactory` реализует `IFtdiDeviceFactory<MyDevice>`, а `MyDevice` реализует `IFtdiDevice`. Фабрика заполняет объект сведениями, полученными от драйвера: флагами, типом, идентификаторами, серийным номером и описанием устройства.

## Основные компоненты

| Компонент | Назначение |
| --- | --- |
| `Ftdi` | Точка входа: поиск устройств, получение сведений о них и открытие каналов. |
| `FtdiDevice` | Стандартное описание устройства и открытие канала по серийному номеру, описанию или расположению. |
| `IFtdiDevice` | Контракт описания FTDI-устройства для пользовательских типов. |
| `IFtdiDeviceFactory<T>` | Контракт фабрики, создающей описания устройств нужного типа. |
| `DefaultFtdiFactory` | Стандартная фабрика объектов `FtdiDevice`. |
| `FtdiChannel` | Обмен данными, настройка канала и доступ к функциям открытого устройства. |
| `FtdiSettings` | Параметры последовательного обмена, таймауты, управление потоком и битовый режим. |
| `FtdiException` | Исключение с кодом состояния `FtdiStatus`, возвращённым драйвером. |
| `FtdiNative` | Внутренние объявления P/Invoke для функций FTDI D2XX. |
| `FtdiSafeHandle` | Безопасное владение и закрытие нативного дескриптора устройства. |
| `FtdiEnums.cs` | Статусы, флаги и перечисления режимов FTDI. |

## Структура проекта

```text
FtdiSharp/
├── Ftdi.cs                  — обнаружение и открытие устройств
├── FtdiDevice.cs            — стандартное описание устройства
├── IFtdiDevice.cs           — контракт описания устройства
├── IFtdiDeviceFactory.cs    — контракт фабрики устройств
├── DefaultFtdiFactory.cs    — стандартная фабрика устройств
├── FtdiChannel.cs           — основной API открытого канала
├── FtdiSettings.cs          — настройки соединения
├── FtdiEnums.cs             — перечисления и флаги FTDI
├── FtdiException.cs         — представление ошибок D2XX
├── FtdiExtensions.cs        — внутренние вспомогательные методы
├── FtdiNative.cs            — импорт нативных функций D2XX
└── FtdiSafeHandle.cs        — управление временем жизни дескриптора
```

## Сборка

Из корня репозитория:

```bash
dotnet build FtdiSharp/FtdiSharp.csproj
```

Для запуска приложения, использующего библиотеку, нативный драйвер D2XX должен быть установлен и доступен загрузчику операционной системы.
